# StartX

StartX 是一款面向 Windows 10 / 11 的桌面效率工具，专为高频使用计算机的用户设计，帮助你更快打开常用程序、资源和功能，减少重复查找和切换带来的时间浪费。

简单、高效、轻量，让桌面工作更专注、更流畅。

## 为什么选择 StartX？

我们常常在工作中花费大量时间重复：
- 打开常用程序
- 查找资源和文件
- 切换不同工具
- 反复定位常用功能

StartX 的目标很简单：让这些操作更快、更少干扰，让你把精力放回真正重要的事情上。

## 核心优势

- 快速访问常用程序

## 使用方式

### 系统要求
- Windows 10 / 11
- 建议以管理员权限运行
- 若进行源码编译，需要 Delphi / RAD Studio

### 快速开始
1. 下载最新发布版
2. 解压并运行 `StartX.exe`
3. 配置常用启动项
4. 开始高效使用桌面工具

> 某些功能可能需要管理员权限才能正常运行，具体取决于你的系统环境和使用方式。

## 开发者说明

如果你希望自行编译此项目，请使用 Delphi / RAD Studio 打开项目文件，并进行编译。

### 编译步骤
1. 安装 Delphi / RAD Studio
2. 打开对应的 `.dpr` 或 `.dproj` 文件
3. 选择 Release 配置
4. 编译并生成可执行文件
