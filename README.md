# StartX

StartX 是一款为 Windows 11 / Windows 10 设计的桌面效率工具，帮助用户快速打开常用程序、资源和功能，减少反复查找和切换带来的时间损耗。

[![License](https://img.shields.io/badge/license-GPL%20v2-blue.svg)]()
[![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-lightgrey)]()
[![Language](https://img.shields.io/badge/language-Delphi-EE3A43)]()

## 亮点
- 快速启动常用应用和资源
- 轻量化界面，不干扰工作流
- 适合办公、开发、日常使用场景
- 支持 Windows 11 体验
- 可作为桌面 Dock / 启动器工具使用

## 适用场景
- 需要快速打开常用软件的人
- 经常打开多个程序但希望减少切换成本的用户
- 想要类似桌面 Dock / 启动器体验的 Windows 用户
- 开发者/设计师/办公人士

## 功能特点
- 快速访问常用程序
- 资源管理入口
- 提升桌面效率
- 最小化到托盘运行
- 适配 Windows 11 界面风格

## 快速开始
### 运行要求
- Windows 10 / 11
- Delphi / RAD Studio（如需自行编译）
- 以管理员身份运行（如程序需要系统级权限）

### 直接使用
1. 下载发布版程序
2. 解压后运行 `StartX.exe`
3. 根据需要配置常用启动项
